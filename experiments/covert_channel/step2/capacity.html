Bit error rate vs symbol period

N = 3 · error bars = ±1 sd

Shorter symbols pack more bits per second but give the receiver's IPC less time to settle, so errors climb. Over a short transmission with a fresh threshold the channel is error-free down to T = 12k; over a long 256-bit payload a static threshold drifts with mcf's own phases and BER rises earlier — the gap is decoder tracking, not the channel.

Usable capacity vs symbol period

BSC capacity = rate × (1 − H(BER))

Capacity is the error-corrected information rate. It rises with symbol rate until errors overwhelm the gain, peaking near the knee, then collapses. The long-payload curve peaks at ~2.3 b/Mcyc; a drift-tracking decoder (the short-transmission line) reaches ~5.9, so 2.3 is a conservative floor for this mechanism.

Method & honest limits

read before citing

Signalling. One schedule row per symbol period T (receiver instructions): duty 100 for a 1, duty 0 for a 0. A 16-bit 1010… preamble calibrates the decode threshold; payload bits are a seeded PN sequence. No new simulator code — same gate as Step 1.

Decoder. Bin the receiver's own IPC per symbol, threshold against the preamble levels (IPC low ⇒ bit 1). BER over payload only. It's a simple fixed-threshold decoder; an adaptive one would recover more (see the short-transmission line).

Capacity. Binary-symmetric-channel capacity, rate × (1 − H(BER)), in bits per megacycle. The bits/sec figure assumes a 4 GHz core and is labelled as such — the simulator is frequency-agnostic.

Clock assumption. The schedule is receiver-instruction-clocked, so sender and receiver share an instruction-count clock. Fine for a cooperating-sender upper bound; a real channel needs a shared wall clock.

Stock channel. Unmodified 4-quartile bucket, recomputed every 256 cycles. Low capacity is the honest property of real Pythia, reported as a result, not engineered away.

Scope. One receiver (mcf) + one contrast (gcc), one sender pattern, N = 3 seeds at the reported periods (N = 1 coarse sweep to locate the range). Stealth/detectability is Step 4.

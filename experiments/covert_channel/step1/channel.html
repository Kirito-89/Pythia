Method & honest limits

read before citing

Harness. Two-core ChampSim, perceptron-no-multi-no-ship-2core, stock pythia.ini. Core 0 = receiver (429.mcf, Pythia on). Core 1 = sender (470.lbm), gated at the trace level.

Sender. Open-loop fixed schedule — no victim-IPC oracle. Duty 100 passes the sender's full memory stream; duty 0 strips its memory ops. Same build, traces, and schedule across classes; only the duty differs, and core count is pinned at 2.

Observables are self-read. IPC and action-0 are the receiver reading its own counters — legitimate for a cooperating covert receiver, so the steering phase's oracle caveat does not apply here.

Stock channel. The DRAM bucket is the unmodified 4-quartile signal recomputed each bandwidth epoch. Low channel capacity is a property of real Pythia, not a strawman — that is the point.

Phase confound removed. Beyond the marginal histograms, a paired comparison bins both runs by receiver instruction: 73/73 bins slow under pressure (median −85.7%), so the shift is the sender, not mcf's own phases.

Scope. Single run per class (Step-1 pilot; separation is immediate and needs no repeats). 5M warmup + 15M measured. Capacity, BER, and error bars are Step 2.
